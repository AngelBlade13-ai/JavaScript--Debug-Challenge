# JavaScript Debug Challenge

A debugging practice project with HTML, CSS, and JavaScript fixes. The page includes an input field that mirrors typed text into the page and a simple math function tested in the console.

## Features

- Text input event listener
- Live display update
- Simple addition function
- Debugged selectors and function behavior

## How To Run

Open `index.html` in a browser and use the input field. Check the browser console for the math output.

## Files

```text
index.html
styles.css
script.js
```

## What I Practiced

- Finding selector mismatches
- Fixing JavaScript errors
- Testing with browser console output
- Connecting form input to page output
